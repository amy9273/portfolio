## 🌌 Overview

**A/B Portfolio** is built around the conceptual identity **NEBULA** (_"A space for ideas to become systems"_). It is an immersive, high-performance web experience crafted to demonstrate backend engineering discipline, systems thinking, and creative technology.

- **Theme Rhythm**: Alternating mixed-theme environment blending dark violet deep space (`#171021`, `#29183B`) with light cloud editorial surfaces (`#F6F3FA`, `#E9E3F0`).
- **Signature 3D Element**: Procedural Three.js violet orbital core with real-time mouse parallax and lightweight mobile fallbacks.
- **Backend Showcases**: Deep-dive interactive architectural case studies for multi-tenant billing engines, token-bucket rate limiters, and real-time incident queues.
- **Verified Credentials**: Dedicated showcases for 9 professional certifications across Cisco Networking, DataCamp SQL/Python, and Coursera/UMichigan.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router with Turbopack)
- **Language**: TypeScript 5.7+ (Strict Mode)
- **Styling**: Tailwind CSS with custom NEBULA violet tokens
- **Animations**: Framer Motion (spring physics, layout morphs)
- **3D Graphics**: Three.js (procedural WebGL glass & metallic orbital rings)
- **Icons**: Lucide React
- **Typography**: Space Grotesk (display), Inter (body), JetBrains Mono (technical labels)
- **Deployment**: Vercel
