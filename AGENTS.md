# Multi-Agent Workflow Guidelines — A/B Portfolio

## Project Purpose
High-performance personal developer portfolio for **Angel Amaya Balion (A/B)**, built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, and Three.js.

## Key Directives
- **Strict Brand Identity**: The brand is **A/B** (wordmark) with visual concept **NEBULA** ("A space for ideas to become systems").
- **Signature 3D Element**: Procedural / GLB 3D violet orbital core that remains lightweight, responsive, and includes a zero-overhead mobile CSS/SVG fallback.
- **Mixed Theme Execution**: 
  - Dark Violet (`#171021`, `#29183B`) for Hero, Selected Work, and Contact.
  - Light Lavender/Cloud (`#F6F3FA`, `#E9E3F0`) for About, Behind the Systems, and Experience.
- **Developer Proof-of-Work**: Emphasize backend engineering decisions (multi-tenancy, token bucket concurrency, Redis queues, database transactions) over generic buzzwords.
